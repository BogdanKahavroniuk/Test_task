Проект створений для менеджингу зарплат боусів і посад дозволяє додавати вручну або завантажувати дані з стороньього джерела  .В модулі Models знаходяться класи який імплементує логіку нарахування зарплат та бонусів співробітників .Utils призначений для валыідації розрахунків . Інтерфейс реалізований у Views за допомогою Tkinter . Структура проекту зручна для переносу інтерфейсу в web версыю за допомогою FastApi чи інших веб фреймворків Django чи Flask
